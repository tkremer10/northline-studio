NORTHLINE STUDIO — PORTFOLIO WEBSITE

1. Open index.html locally to preview.
2. Choose your actual business name before publishing; Northline is a suggested placeholder.
3. Replace the portfolio's 'Add demo link' text with clickable links to your live GitHub Pages sites.
4. Connect a real form service (Formspree, Netlify Forms with compatible hosting, etc.) before accepting customer inquiries. The demo currently only copies inquiries.
5. Update pricing, business description, contact information, and scope before selling services.
6. Create a public GitHub repository named northline-studio, upload index.html to the repository root, then enable Settings > Pages > Deploy from a branch > main > root.

Note: GitHub Pages has restrictions on commercial use. Check its current terms and consider Cloudflare Pages or Netlify for a live commercial business website.
